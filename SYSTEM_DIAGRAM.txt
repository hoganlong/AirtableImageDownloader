DATA FLOW SEQUENCE:

1. START → Load Configuration (appsettings.json)
              ↓
2. Validate API Key & Base ID
              ↓
3. Process ARTWORK_IMAGE
              ↓
   ├─→ Fetch Records (paginated API calls)
   │          ↓
   ├─→ For each record:
   │   ├─→ Extract record ID (e.g., recABC)
   │   ├─→ Find attachment fields
   │   └─→ For each attachment:
   │       ├─→ Check: Does artwork_recABC_1920x1080.jpg exist?
   │       │   ├─ YES → Skip (⊘)
   │       │   └─ NO  → Download (✓)
   │       └─→ Process thumbnails (small, large)
   │
4. Process ARCHIVE_IMAGE (same steps)
              ↓
5. Report Statistics & Complete

═══════════════════════════════════════════════════════════════════════════════

NAMING PATTERN:

  artwork_recA1B2C3D4_1920x1080.jpg
  │       │           │         └── Extension (.jpg, .png, .gif)
  │       │           └────────── Size/Dimensions
  │       └────────────────────── Airtable Record ID
  └────────────────────────────── Table Prefix (artwork/archive)

SIZE VARIANTS:
  • Full size:  {width}x{height}              (e.g., 1920x1080)
  • Thumbnail:  {name}_{width}x{height}       (e.g., small_200x150)
